This tool is designed to help student understand exactly what happens inside the computer when a loop runs, to mastering Python `for` loops and the `range()` function. 

## 🛠️ How to Use This Tool

This application has two main learning modes, which you can switch between using the tabs at the top:

### 1. Range Explorer
The `range()` function in Python is a powerful way to generate a sequence of numbers. 
- **Start:** Where the counting begins.
- **Stop:** Where the counting ends (remember, Python stops *before* this number!).
- **Step:** How much to jump by with each count. Try positive numbers to count up, or negative numbers to count down!
**Action:** Change the numbers in the code block and click **"Run Loop"** to watch the numbers generate one by one in the console below.

### 2. Multiplication Loop
Here, you'll see a practical, real-world use of a `for` loop: creating a multiplication table.
- Enter a **Target Number** in the input box.
- Click **"Generate"**.
- Watch how the `range(1, 11)` function loops 10 times, multiplying your target number by `i` each time to build the table dynamically!
